DESPLIEGUE MANUAL EN NETLIFY
1. Descomprime este ZIP.
2. En Netlify: Add new project / Deploy manually.
3. Arrastra la carpeta completa `martha_patricia_site_netlify` (no el ZIP).
4. Espera el deploy y abre la URL *.netlify.app.
5. Prueba navegación, WhatsApp, LinkedIn, teléfono y formulario.
6. Cuando todo funcione, agrega tu dominio en Domain management.

No requiere npm, build command ni AI Studio. Es un sitio HTML estático.
