ENTREGABLES PARA CLIENTES — cómo compartir lo que haces en Claude con tu propia marca

1. CREA LA CARPETA DEL CLIENTE (una sola vez)
   Dentro de /entregables crea una carpeta con el nombre del cliente y 4 letras/números
   al azar, para que nadie adivine el enlace. Ej.: emotiva-7k2q
   Opcional: agrega un archivo _cliente.json con:
     { "nombre": "EMOTIVA", "mensaje": "Aquí están los avances del proyecto de datos." }
   Si no lo agregas, el nombre se toma de la carpeta ("emotiva-7k2q" -> "Emotiva").

2. DESCARGA EL ENTREGABLE DE CLAUDE
   - Página o tablero (HTML): en el artefacto, usa Descargar / Download y guarda el .html.
   - Documento o presentación: expórtalo como PDF.
   Ponle un nombre claro, sin espacios: diagnostico-de-datos.html, propuesta.pdf
   Opcional: fecha al inicio para ordenarlos: 2026-11-12_propuesta.pdf

3. SÚBELO A LA CARPETA DEL CLIENTE (GitHub > entregables > carpeta > Add file > Upload files)
   Sube SOLO el archivo nuevo. No borres ni reemplaces carpetas.

4. COMPARTE EL ENLACE (listo 1–2 minutos después de subirlo)
   - Un entregable:  https://marthapatriciaortiz.com/entregables/emotiva-7k2q/diagnostico-de-datos/
   - Todos:          https://marthapatriciaortiz.com/entregables/emotiva-7k2q/
   El título que ve el cliente es el <title> del HTML (o el nombre del archivo si es PDF).

CLAVE OPCIONAL POR CLIENTE
   En Netlify > Site configuration > Environment variables, crea ENTREGABLES_CLAVES con:
     {"emotiva-7k2q": "una-clave-para-emotiva", "otro-cliente-x9p3": "otra-clave"}
   Los clientes que estén ahí verán una pantalla para escribir su clave (se recuerda 30 días).
   Los que no estén, entran solo con el enlace.

IMPORTANTE
   - Estas páginas no aparecen en Google (noindex) ni en el menú del sitio.
   - Mientras el repositorio de GitHub sea público, cualquiera podría ver estos archivos
     en github.com. Para documentos confidenciales, haz el repositorio privado
     (GitHub > Settings > General > Danger Zone > Change visibility). Netlify sigue funcionando.
   - Los artefactos de Claude que usan tus conectores o guardan datos en Claude
     no funcionan fuera de Claude; para esos, comparte un PDF.
